# Riven — Weapon Assets

Upload the finished textured Azure Moonreaper weapon GLB into this folder.

Recommended name: `Riven_Azure_Moonreaper.glb`.

One weapon model is sufficient: Crownfall will create separate visual instances for Riven's two scythes. The game already owns their authoritative orbit, launch, park, and recall states. Integration will be handled in a separate production goal.

This folder is only for 3D weapon assets, not Riven's existing animated character GLB.
