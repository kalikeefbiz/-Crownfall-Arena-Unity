# Goal 015 — rejected experiment, historical evidence

These screenshots, measurements and receipts describe the retired Goal 015 build.
The founder subsequently reported that its approximately 240 MB map crashed a
physical iPhone browser during loading and rejected it for mobile gameplay.
Automated test passes here do not override that result.

These files are retained for audit history; they do not publish or initialize the
preview. See [cleanup verification](../../GOAL_015_CLEANUP.md) and the separate
`../015-cleanup/` receipts for the current state.
